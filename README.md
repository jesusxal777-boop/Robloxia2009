# Robloxia 2009

Classic Roblox 2009 style map recreation inspired by **Happy Home in Robloxia**.

- Procedural map generation (plaza, Happy Home, construction yard, roleplay district, obby, nature)
- Asset loading with safe fallback
- Secret basement → ARG twist
- Built for **Rojo**

## Quick start

```bash
# Clone
git clone https://github.com/jesusxal777-boop/Robloxia2009.git
cd Robloxia2009

# Serve with Rojo
rojo serve
```

Then in Roblox Studio:
1. Install the Rojo plugin
2. Connect to `localhost:34872`
3. Play

## ARG Trigger

Enter the 3rd house in the Roleplay District and interact with the hatch using the built-in Roblox prompt (E / click / touch). The PC prompt appears in the hidden room; type the displayed code in chat to continue.

## Notes

- Map is fully generated by code.
- Recommended assets are documented in the original research (Classic Happy Home ID `2833495991`, etc.).
- No complex UI — only the map and physical interactions.


## RP Expansion (experimental)

The roleplay systems are implemented in `src/ServerScriptService/Robloxia/RPExpansion.lua` and start automatically after the procedural map is built. The module clones the named RP assets from `ServerStorage`; it does not embed those models in the Rojo source tree. Purchased TVs and PCs must be installed on an available table surface inside the player's claimed house.

Features include claimable model houses, default furniture/TV, Money leaderboard, work-shift prompts, a procedural Tech Store, grocery bag capacity and refrigerator storage, crate delivery for purchased TVs/PCs, vehicle purchase/repaint/service prompts, and rare tornado alerts.

**Important:** keep the original place file and its `ServerStorage` models. Rojo syncs the scripts; it does not recreate the binary models from the uploaded `.rbxl`. Test in Studio before publishing.
