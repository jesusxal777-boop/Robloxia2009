## Política de carga
1. Intentar InsertService:LoadAsset(assetId)
2. Si falla o el modelo tiene scripts sospechosos → usar reconstrucción procedural (MapBuilder)
3. Siempre tener versión procedural como respaldo
4. Anclar todo después de insertar
5. Mover a la carpeta correcta en Workspace/Robloxia2009
