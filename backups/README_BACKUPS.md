# Sistema de respaldos — Robloxia 2009

Fecha de creación: 2026-10-24

## Procedimiento recomendado

1. **Antes de cualquier cambio grande** en Studio:
   - File → Save to File As…
   - Nombre: `Robloxia2009_YYYY-MM-DD_HHmm.rbxl`

2. **Version History** (si el lugar está en Roblox)

3. Nunca sobrescribas el único archivo bueno.

El mapa procedural siempre funciona aunque los assets fallen.
